# Admin panel

## Setup

1. Start the backend server from the server app.
2. Start the admin app with `npm run dev`.
3. Create or update a user record in the database with `raw.userType = 'admin'` and an email/password pair.
4. Sign in at `/admin/login`.

## Features

- Admin login with email and password
- Password change flow
- Dashboard with core commerce stats
- Categories, products, and shops management screens
